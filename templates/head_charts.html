{% comment %} Chart.js y su plugin de etiquetas, que usan las tres páginas de estadísticas. La versión va FIJA a propósito. Antes se pedía `npm/chart.js` a secas, o sea la última que hubiera: un major con cambios de API habría roto las tres páginas en silencio, sin que nada del repo cambiara. Al fijarla se comprobó que estas dos sirven exactamente los mismos bytes que servía la URL sin versión. El `integrity` es el hash de esos bytes: si el CDN devolviera otra cosa, el navegador se niega a ejecutarlo en vez de confiar. Al subir de versión hay que recalcularlo, o el script deja de cargar: curl -s https://cdn.jsdelivr.net/npm/chart.js@X.Y.Z | openssl dgst -sha384 -binary | openssl base64 -A {% endcomment %}
